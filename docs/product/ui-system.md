# UI system

The shell uses original THE Browser branding, semantic color tokens, visible focus rings, 44px minimum touch targets where appropriate, and WCAG-conscious contrast. Components: application frame, workspace switcher, stack rail, spatial canvas, card frame/header, compact URL editor, contextual menu, command palette, dialogs, and notification region.

Cards distinguish `active`, `inactive`, `loading`, `sleeping`, `crashed`, and `private` through text/icon/color plus accessible labels—not color alone. Motion is short, interruptible, and disabled/reduced when the OS requests reduced motion. No control is rendered as enabled until its backend command works.
