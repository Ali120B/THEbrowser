# Interaction model

A user opens or selects a workspace, then sees stacks and their cards on a spatial canvas. Selecting a card focuses it and wakes it when sleeping. A card header provides compact navigation and an overflow menu; drag moves, handles resize, and a stack target changes membership after feedback. The command palette provides discoverable keyboard actions.

Planned commands include create/focus/close card, navigate, back/forward/reload, move/resize/maximize, sleep/wake, create/rename/switch stack and workspace, and reopen recently closed cards. Commands are implemented incrementally and unavailable commands are omitted or labelled unavailable—never simulated.
