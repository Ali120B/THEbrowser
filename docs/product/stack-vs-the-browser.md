# Stack-inspired, THE Browser-original

THE Browser takes inspiration from the public spatial browsing idea: cards, grouped work, compact controls, and a calm canvas. It does not represent itself as Stack, reuse Stack branding/assets, or copy proprietary implementation.

| Concept | Why it works | THE Browser decision |
|---|---|---|
| Websites as cards | Relationships remain visible | Implement with owned Chromium content views and real navigation. |
| Grouped work | Reduces tab overload | Persistent stacks inside workspaces with explicit recovery. |
| Compact navigation | More room for content | Per-card chrome with keyboard-accessible commands. |
| Flexible presentation | Different tasks need different density | Add modes only after their behavior and accessibility are specified. |
| Spatial persistence | Work resumes where it stopped | Use schema-versioned, atomic local files and unloaded restore. |
